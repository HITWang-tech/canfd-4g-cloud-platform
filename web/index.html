数据说明

CAN2 保留基础信号，并扩展文档要求的动力、后处理及 PTO 定义；CAN1 单独解析 IN1 传感器力；无有效数据的指标显示“—”。CAN1 只解析传感器力（500 kbit/s）；CAN2 只解析整车 J1939（250 kbit/s）。动力参数按当前 ECU 地址隔离，标准帧传感器按精确 CAN ID 匹配。网页不改变记录仪硬件波特率。

累计燃油仅对当前已载入记录积分，实时缓存滚动后不代表完整试验总量。大气压力、温度按 DBC 的 AMB 报文提取；最大可用扭矩来自 EEC2，行程燃油来自 LFC。

演示数据为合成数据，仅用于展示仪表、曲线和地图联动；导入后切换为真实数据回放。
